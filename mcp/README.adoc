== Documentation principles

* Lead with the operational outcome, not the internal service name.
* Treat MCP access as tenant-scoped and read-only unless a page explicitly says otherwise.
* Discover metadata before constructing object, log, or alert queries.
* Never place access tokens, credentials, private addresses, or complete webhook endpoints in prompts or examples.
* Use fictional resource names in all published examples.

== Publishing

The files use AsciiDoc and relative links so they can be imported into a documentation platform or rendered by a static-site generator. Replace placeholders such as +{lt}DII_MCP_SERVER_URL{gt}+ only in a secure deployment-specific publishing pipeline.
